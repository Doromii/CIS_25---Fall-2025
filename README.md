# Module 6:
This code contains a class named "schoolSupplies". It is "public" in order to allow for the members to be accessible outside of the class.
There are two attributes within the class: name (string type) and quantity (integer type).

There is a saveToFile function to write the data in a separate text file  
and a loadFromFile function that reads a string from the text file and displays it.

The main code takes some object (in this case "pencil") and sets the class' attributes for name and quantity.
Then the object and it's attributes are saved to a text file. 
From that text file, you can load a line of what was saved.

There is a second example with "paper" as an object with name and quantity attributes different from "pencil", 
but still within the same class schoolSupplies.
