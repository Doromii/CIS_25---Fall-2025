# CIS_25 - Fall 2025
 Programming Using C++
-----------------------------------------------------
**Week 7 - Module 4**

Part 1:

The user is prompted to select a bevarage from a list (1, 2, or 3). The integer input is assigned to the int variable "choice".
Then it goes through a series of if statements checking to see if 'choice' is either 1, 2, or 3. When choice == 1, 2, or 3 the program outputs a statement saying "You selected (drink of choice)". Once it gets through the if statements, it prints a closing statement. If the user inputs anything other than 1, 2, or 3 the program outputs that the input is invalid, then is closed.


Part 2:

The user is asked to input three numbers (type float). The program then compares each input in order to output the largest of the three numbers. The first if statement takes the first number and checks to see if it's greater than or equal to the second number. If it is, then a nested if statement is read. The first number is compared to the third number and the program outputs either the first or third number (whichever one is the largest). 

If the first number is not greater than or equal to the second, then the program compares the second and third numbers. The largest number the program will output will depend on if the second number is greater than or equal to the third number.
